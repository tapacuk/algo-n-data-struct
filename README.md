# Algorithms and Data Structures

### Завдання першого рівня

Виконати такі дії:
– описати студента згідно з варіантом завдання (дод. 3, табл. Д3.1, «Поля класу «Студент»»);
– описати бінарне дерево;
– створити екземпляр бінарного дерева;
– додати елементи до дерева;
– вивести вміст дерева у табличному вигляді згідно з заданим способом обходу дерева (дод. 3, табл. Д3.1, «Обхід дерева»).

### Завдання другого рівня

– додати до опису бінарного дерева метод, який шукає у дереві вузол за визначеним у варіанті завдання критерієм пошуку (дод. 3, табл. Д3.2);
– створити екземпляр бінарного дерева;
– додати елементи до дерева;
– вивести вміст дерева у табличному вигляді згідно з заданим способом обходу дерева (дод. 3, табл. Д3.1, «Обхід дерева»);
– знайти та вивести вузли дерева за визначеним критерієм пошуку.

### Завдання третього рівня

– додати до опису бінарного дерева метод, який видаляє з дерева вузли, що відповідають визначеному у варіанті завдання критерію пошуку (дод. 3, табл. Д3.2);
– створити екземпляр бінарного дерева;
– додати елементи до дерева;
– вивести вміст дерева у табличному вигляді згідно з заданим способом обходу дерева (дод. 3, табл. Д3.1, «Обхід дерева»);
– знайти та видалити вузли дерева за визначеним критерієм пошуку;
– вивести вміст дерева в табличному вигляді.

### Дані:

Клас студент: Прізвище, ім'я, курс, студентський квиток, дата народження
Обхід дерева: Паралельний
Критерій: Студенти 2-го курсу, які народилися взимку

Дерево будується так, щоб вузли-кандидати на видалення охоплювали
всі можливі варіанти розміщення:

```
               500
              /    \
           300       700
          /   \     /   \
        100   400 600   800
                \          \
```
